## About & Purpose

This project provides the parent Maven POM for an independent, community-maintained fork of **Apache Tiles** (retired to the [Apache Attic](https://apache.org)).

Its primary goal is to **maintain and modernize the build configuration and codebase to ensure full compatibility with Jakarta EE** (migrating away from legacy `javax.*` namespaces to `jakarta.*`).

* **Equivalent original artifact:** `org.apache.tiles:tiles-master`
* **New artifact coordinates:** `io.github.laurentschoelens.tiles:tiles-master`
